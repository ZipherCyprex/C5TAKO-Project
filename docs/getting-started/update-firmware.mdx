หน้านี้ช่วยให้คุณอัปเดตเฟิร์มแวร์ C5TAKO ผ่านเว็บ โดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

ใช้ [Web Firmware Installer](https://www.ziphers.space/flash) กับ Chrome หรือ Edge

## ก่อนเริ่ม

- ใช้คอมพิวเตอร์และเปิดเว็บด้วย Chrome หรือ Edge
- เตรียมสาย USB ที่ **ส่งข้อมูลได้** ไม่ใช่สายชาร์จอย่างเดียว
- ชาร์จแบตเตอรี่ให้เพียงพอ
- ปิดโปรแกรมที่กำลังใช้พอร์ต Serial ของเครื่อง
- สำรองไฟล์สำคัญจาก Storage ก่อนอัปเดต

<Warning>

ห้ามถอดสาย ปิดคอมพิวเตอร์ หรือปิดหน้าเว็บระหว่างติดตั้งเฟิร์มแวร์

</Warning>

## ขั้นตอนอัปเดต

<Steps>
  <Step title="เปิด Web Firmware Installer">
    ไปที่ [ziphers.space/flash](https://www.ziphers.space/flash)
  </Step>
  <Step title="เลือกบอร์ด">
    เลือก `ESP32-C5` แล้วกด `Next`
  </Step>
  <Step title="เลือก Firmware">
    เลือก `C5 TAKO` แล้วกด `Next`
  </Step>
  <Step title="เลือกเวอร์ชัน">
    เลือก `C5 TAKO XIAO ESP32-C5` เวอร์ชันล่าสุด และตรวจว่าแสดง `ESP32-C5` กับ `8MB Flash`
  </Step>
  <Step title="เชื่อมต่อเครื่อง">
    กด `ไปหน้าติดตั้ง` แล้วกด `Connect` เลือกพอร์ต USB ของ C5TAKO จากหน้าต่างเบราว์เซอร์
  </Step>
  <Step title="ติดตั้ง">
    เมื่อเชื่อมต่อสำเร็จ ปุ่ม `ติดตั้งเฟิร์มแวร์` จะกดได้ ทำตามข้อความบนหน้าจอและรอจนระบบแจ้งว่าเสร็จ
  </Step>
  <Step title="เปิดเครื่องใหม่">
    หลังติดตั้งเสร็จ ให้ปิด–เปิดเครื่องหนึ่งครั้ง แล้วตรวจว่าเข้าสู่เมนูหลักได้ตามปกติ
  </Step>
</Steps>

</Info>

## ถ้าเว็บไม่พบเครื่อง

ลองตามลำดับนี้:

1. เปลี่ยนเป็นสาย USB ที่ส่งข้อมูลได้
2. เสียบกับพอร์ตคอมพิวเตอร์โดยตรง ไม่ผ่าน USB Hub
3. ปิด Serial Monitor, Arduino IDE หรือโปรแกรมอื่นที่ใช้พอร์ตอยู่
4. ถอดสาย รอประมาณ 5 วินาที แล้วเสียบใหม่
5. รีเฟรชหน้าเว็บและกด `Connect` อีกครั้ง
6. หากยังไม่พบ ให้หยุดทำรายการและติดต่อผู้ขาย

<Note>

ชื่อเวอร์ชันบนเว็บไซต์อาจเปลี่ยนเมื่อมีรุ่นใหม่ ให้ยึดชื่อ `C5 TAKO`, บอร์ด `ESP32-C5` และ `8MB Flash` เป็นหลัก

</Note>
