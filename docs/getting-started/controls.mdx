C5TAKO™ ใช้ปุ่ม 5 ทิศทางชุดเดียว หน้านี้ช่วยให้คุณเลือกเมนู ย้อนกลับ และหยุดฟีเจอร์ที่กำลังทำงาน

![ตำแหน่งปุ่มควบคุมบน C5TAKO™](/images/device/main-menu-handheld.jpeg)


## ปุ่มแต่ละทิศทาง

| การกด | การทำงานทั่วไป |
| --- | --- |
| ขึ้น / ลง | เลื่อนรายการ |
| ขวา | เปิดรายการ |
| กดกลางสั้น ๆ | เปิด ยืนยัน หรือเริ่มทำงาน |
| ซ้าย | ย้อนกลับหนึ่งระดับ |
| กดกลางค้างประมาณ 1 วินาที | หยุดฟีเจอร์หรือออกจากหน้าทำงาน |

บางหน้าจะใช้ปุ่มต่างจากตาราง เช่น ซ้าย/ขวาเพื่อเปลี่ยนค่า ให้ทำตามคำใบ้ด้านล่างหน้าจอเป็นหลัก

## วิธีอ่านเส้นทางเมนู

ลูกศร `→` หมายถึง “เลือกเมนูถัดไป” เช่น:

```text
SETTINGS → Display → Theme
```

1. เลื่อนไปที่ `SETTINGS` แล้วกดขวาหรือกดกลาง
2. เลือก `Display`
3. เลือก `Theme`

ไม่ต้องจำเส้นทาง เปิดคู่มือไว้แล้วทำจากซ้ายไปขวาทีละชื่อ

## หยุดฟีเจอร์ที่กำลังทำงาน

1. กดปุ่มกลางค้างประมาณ 1 วินาที
2. ปล่อยเมื่อหน้าจอหยุดทำงานหรือกลับเมนู
3. หากเครื่องยังไม่ตอบสนอง ให้ปิดสวิตช์ รอประมาณ 5 วินาที แล้วเปิดใหม่

ใช้วิธีนี้กับหน้าสแกน หน้าตรวจสอบสัญญาณ และเกม เว้นแต่คำใบ้บนหน้าจอระบุวิธีอื่น

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** สาธิต “เลื่อนเมนู → เข้า WIFI → ย้อนกลับด้วยซ้าย → หยุดหน้าทำงานด้วยกดกลางค้าง”
</Info>

## ถ้ารายการเลื่อนเร็วเกินไป

ปุ่มทิศทางรองรับการกดค้างเพื่อเลื่อนต่อเนื่อง หากต้องการเลื่อนครั้งละหนึ่งรายการ ให้แตะแล้วปล่อยทันที

ขั้นตอนถัดไป: [ตั้งค่าที่แนะนำ](/getting-started/first-settings)
