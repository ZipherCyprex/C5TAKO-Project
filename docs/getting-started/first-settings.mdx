---
title: "ตั้งค่าที่แนะนำ"
description: "เช็กลิสต์การตั้งค่าหลังเปิดเครื่องครั้งแรก"
icon: "sliders-horizontal"
---

หลังตรวจว่าเครื่องและปุ่มทำงานแล้ว ให้ตั้งค่า 3 รายการนี้ก่อน รายการอื่นกลับมาปรับภายหลังได้

<Steps>
  <Step title="ตั้งรหัสผ่าน">
    เปิด `SETTINGS → Security → Set Password` แล้วสร้างรูปแบบการกด 4 ครั้ง ดูรายละเอียดที่ [ตั้ง เปลี่ยน หรือปิดรหัสผ่าน](/features/settings#security)
  </Step>
  <Step title="เลือก Theme">
    เปิด `SETTINGS → Display UI → Theme` แล้วเลือกชุดสีที่ต้องการ ดูตัวเลือกที่ [ตั้งค่าหน้าจอ](/features/settings#display-ui)
  </Step>
  <Step title="ปรับความสว่าง">
    เปิด `SETTINGS → Display UI → Brightness` เริ่มที่ 25–50% แล้วปรับตามสภาพแสง ดูรายละเอียดที่ [ตั้งค่าหน้าจอ](/features/settings#display-ui)
  </Step>
</Steps>

<Warning>

รหัสผ่านเป็นรูปแบบการกด 4 ครั้ง ควรเก็บลำดับไว้ในที่ปลอดภัย หากลืมอาจต้องติดต่อผู้ขายเพื่อขอความช่วยเหลือ

</Warning>

เสร็จแล้วไปที่ [เลือกฟีเจอร์](/features/menu-overview) ได้เลย
