---
title: "ตั้งค่าที่แนะนำ"
description: "เช็กลิสต์การตั้งค่าหลังเปิดเครื่องครั้งแรก"
icon: "sliders-horizontal"
---

หลังตรวจว่าเครื่องและปุ่มทำงานแล้ว แนะนำให้ตั้งเพียง 3 เรื่องนี้ ส่วนรายการอื่นกลับมาปรับภายหลังได้

<Steps>
  <Step title="ตั้งรหัสผ่าน">
    เปิด `SETTINGS → Security → Set Password` แล้วทำตาม [วิธีตั้งรหัสผ่าน](/features/settings#security)
  </Step>
  <Step title="เลือก Theme">
    เปิด `SETTINGS → Display UI → Theme` แล้วดูตัวเลือกทั้งหมดที่ [Display UI](/features/settings#display-ui)
  </Step>
  <Step title="ปรับความสว่าง">
    เปิด `SETTINGS → Display UI → Brightness` เริ่มที่ 25–50% แล้วปรับตามสภาพแสง
  </Step>
</Steps>

<Warning>

รหัสผ่านเป็นรูปแบบการกด 4 ครั้ง ควรเก็บลำดับไว้ในที่ปลอดภัย หากลืมอาจต้องติดต่อผู้ขายเพื่อขอความช่วยเหลือ

</Warning>

เสร็จแล้วไปที่ [เลือกฟีเจอร์](/features/menu-overview) ได้เลย
