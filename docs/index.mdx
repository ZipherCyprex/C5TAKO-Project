![C5TAKO](/images/Zipher_c5tako.png)

C5TAKO เป็นอุปกรณ์ทดสอบ Wi‑Fi และ Bluetooth แบบพกพา หน้านี้ช่วยให้คุณเริ่มจากเมนูบนเครื่องและไปยังคู่มือที่ตรงกับงานที่ต้องการทำ

<Warning>

C5TAKO **ไม่กันน้ำ** และฟีเจอร์ทดสอบเครือข่ายควรใช้กับอุปกรณ์ของคุณเองหรือระบบที่ได้รับอนุญาตเท่านั้น

</Warning>

<Info>

⭐ **ฟีเจอร์เด่น:** C5TAKO รองรับ Wi‑Fi ทั้งย่าน **2.4 GHz และ 5 GHz**

</Info>

## เลือกเมนูบนเครื่อง

หากเปิดเครื่องแล้ว ให้เลือกคู่มือตามชื่อเมนูที่เห็นบนหน้าจอ:

| เมนูบนเครื่อง | ใช้ทำอะไร | คู่มือ |
| --- | --- | --- |
| `WIFI` | สแกน ตรวจสอบ และทดสอบ Wi‑Fi 2.4 GHz และ 5 GHz | [เปิดคู่มือ WIFI](/features/wifi-overview) |
| `Bluetooth` | ตรวจสอบและทดสอบอุปกรณ์ BLE | [เปิดคู่มือ Bluetooth](/features/bluetooth-overview) |
| `APP` | ใช้เสียงและไฟจากหน้าจอ | [เปิดคู่มือ APP](/features/apps) |
| `GAME` | เล่นเกม `MAZE` | [เปิดคู่มือ GAME](/features/game) |
| `FILES` | ดูและจัดการไฟล์ | [เปิดคู่มือ FILES](/features/files) |
| `SETTINGS` | ตั้งค่าเครื่อง | [เปิดคู่มือ SETTINGS](/features/settings) |
