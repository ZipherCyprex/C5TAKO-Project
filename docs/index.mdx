![C5TAKO](/images/Zipher_c5tako.png)

C5TAKO เป็นอุปกรณ์ทดสอบ Wi‑Fi และ Bluetooth แบบพกพา เครื่องที่ได้รับพร้อมเปิดใช้งานได้ทันที ไม่ต้องประกอบหรือแฟลชเฟิร์มแวร์ก่อนใช้ครั้งแรก

<Warning>

C5TAKO **ไม่กันน้ำ** และฟีเจอร์ทดสอบเครือข่ายควรใช้กับอุปกรณ์ของคุณเองหรือระบบที่ได้รับอนุญาตเท่านั้น

</Warning>
