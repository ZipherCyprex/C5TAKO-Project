หน้านี้เป็นแผนที่เมนูของ C5TAKO™ ชื่อใน `กรอบ` คือชื่อที่เห็นบนเครื่อง ให้เลือกชื่อเดียวกันเพื่อไปยังคู่มือที่เกี่ยวข้อง

## 🧭 เมนูบนเครื่อง

  </Card>

  </Card>

<Tip>

เมื่อคู่มือแสดงเส้นทาง เช่น `WIFI → SCAN → AP → Scan` ให้เลือกชื่อจากซ้ายไปขวาทีละรายการ ดูวิธีใช้ปุ่มที่ [ปุ่มควบคุมและการนำทาง](/getting-started/controls#วิธีอ่านเส้นทางเมนู)

</Tip>
