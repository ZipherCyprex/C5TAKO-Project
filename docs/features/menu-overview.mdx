ชื่อใน `กรอบ` ตรงกับชื่อบนอุปกรณ์ เลือกชื่อเดียวกันเพื่อไปยังคู่มือที่เกี่ยวข้อง

## 🧭 เมนูบนเครื่อง

<CardGroup cols={2}>
  <Card title="WIFI" icon="wifi" href="/features/wifi-overview">
    ค้นหา ตรวจสอบ และทดสอบเครือข่าย Wi‑Fi
  </Card>
  <Card title="Bluetooth" icon="bluetooth" href="/features/bluetooth-overview">
    ดูและทดสอบอุปกรณ์ BLE
  </Card>
  <Card title="SUB-GHz" icon="radio" href="/features/sub-ghz">
    แสดงเมื่อเครื่องตรวจพบโมดูล CC1101
  </Card>
  <Card title="APP" icon="panels-top-left" href="/features/apps">
    ใช้ Buzzer, Flashlight, MAP และ NMAP
  </Card>
  <Card title="GAME" icon="gamepad-2" href="/features/game">
    เล่น MAZE และ DINO
  </Card>
  <Card title="FILES" icon="folder-open" href="/features/files">
    จัดการไฟล์ Web Files และ Storage
  </Card>
  <Card title="SETTINGS" icon="settings" href="/features/settings">
    ตั้งค่าเสียง หน้าจอ รหัสผ่าน และอุปกรณ์
  </Card>
</CardGroup>

<Tip>

เส้นทาง เช่น `WIFI → SCAN → AP → Scan` หมายถึงเลือกชื่อจากซ้ายไปขวา ดู [วิธีอ่านเส้นทางเมนู](/getting-started/controls#วิธีอ่านเส้นทางเมนู)

</Tip>

![เมนูหลักของ C5TAKO™](/images/device/main-menu.jpeg)

<Note>

`SUB-GHz` แสดงเฉพาะเมื่อพบ CC1101 จึงอาจไม่ปรากฏในรูป

</Note>
