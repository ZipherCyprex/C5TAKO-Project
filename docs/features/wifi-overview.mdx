หน้านี้ช่วยให้คุณเลือกเมนู `WIFI` ให้ตรงกับงานที่ต้องการทำ: สแกนเครือข่าย ตรวจสอบสัญญาณ หรือทดสอบระบบ Wi‑Fi ที่คุณได้รับอนุญาต

<Info>

⭐ **จุดเด่นของ C5TAKO™:** รองรับ Wi‑Fi ทั้งย่าน **2.4 GHz และ 5 GHz**

</Info>

## 🧭 เลือกเมนู

<CardGroup cols={3}>
  <Card title="SCAN" icon="scan-search" href="/features/wifi-scan">
    ค้นหา Router หรืออุปกรณ์ที่เชื่อมต่ออยู่
  </Card>
  <Card title="ATTACK" icon="shield-alert" href="/features/wifi-attack">
    ทดสอบการป้องกันของเครือข่าย
  </Card>
  <Card title="SNIFFER" icon="radar" href="/features/wifi-sniffer">
    ดู Packet สัญญาณรบกวน หรือบันทึก PCAP
  </Card>
</CardGroup>

<Note>
💡 **เริ่มต้นที่ไหนดี?** เริ่มจาก `SCAN` หากต้องการค้นหาและเลือก AP หรือ STA ก่อนใช้เมนูอื่น
</Note>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** ภาพหน้าเมนู WIFI โดยใส่หมายเลขกำกับ SCAN, ATTACK และ SNIFFER
</Info>

## 💡 คำที่เห็นบ่อย

<AccordionGroup>
  <Accordion title="AP คืออะไร?" icon="router">
    `AP` หรือ Access Point คือจุดปล่อย Wi‑Fi เช่น Router ที่บ้านหรือ Hotspot
  </Accordion>
  <Accordion title="STA คืออะไร?" icon="smartphone">
    `STA` คืออุปกรณ์ที่เชื่อมต่อ Wi‑Fi เช่น โทรศัพท์ คอมพิวเตอร์ หรือกล้อง IP ในบางหน้าจออาจเรียกว่า Client
  </Accordion>
  <Accordion title="Packet และ PCAP คืออะไร?" icon="file-archive">
    Packet คือข้อมูลชิ้นเล็ก ๆ ที่ส่งผ่านเครือข่าย ส่วน PCAP คือไฟล์ที่บันทึก Packet ไว้เปิดตรวจสอบภายหลัง
  </Accordion>
</AccordionGroup>
