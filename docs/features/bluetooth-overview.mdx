</Note>

## ถ้าโทรศัพท์ไม่ตอบสนอง

1. ตรวจว่าเปิด Bluetooth บนโทรศัพท์แล้ว
2. ขยับอุปกรณ์เข้ามาใกล้กัน
3. หยุดฟีเจอร์ Bluetooth อื่นบน C5TAKO™
4. ปิด–เปิด Bluetooth บนโทรศัพท์แล้วลองใหม่
