เมนู `ATTACK` ใช้ทดสอบความปลอดภัยของเครือข่าย Wi‑Fi ด้วยการส่ง Packet จำลองหรือสร้างสถานการณ์ผิดปกติ แต่ละฟีเจอร์จะ**ส่งผลกระทบต่อการเชื่อมต่อจริง** เช่น ตัดการเชื่อมต่ออุปกรณ์ หรือทำให้ Router ช้าลง

<Warning>

**ฟีเจอร์ในเมนูนี้จะตัดการเชื่อมต่อหรือรบกวนการทำงานของ Wi‑Fi** ใช้เฉพาะเครือข่ายที่คุณเป็นเจ้าของหรือได้รับอนุญาตอย่างชัดเจน และหยุดทันทีเมื่อทดสอบเสร็จ

</Warning>

## ก่อนเริ่ม

1. อ่านความหมายของเมนูที่จะใช้ด้านล่าง
2. หากตัวเลือกระบุ `Selected AP` หรือ `Selected STA` ให้ [สแกนและเลือกอุปกรณ์](/features/wifi-scan) ก่อน
3. เตรียมอุปกรณ์อีกเครื่องไว้ตรวจผล
4. เปิด [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) ไว้ก่อนเริ่ม

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** การเตรียมทดสอบ “Scan → Select AP → เข้า ATTACK → เริ่ม → กดกลางค้างเพื่อหยุด” โดยใช้ Lab ส่วนตัว
</Info>

## 🧭 แต่ละเมนูใช้ทำอะไร

<AccordionGroup>
  <Accordion title="Deauth — ส่งคำสั่งตัดการเชื่อมต่อ" icon="wifi-off">
    ส่ง Deauthentication Packet เพื่อ**ตัดการเชื่อมต่อ Wi‑Fi** ของอุปกรณ์ในเครือข่ายทดสอบ ใช้ดูว่าอุปกรณ์เชื่อมต่อกลับมาได้รวดเร็วแค่ไหน และระบบตรวจจับได้หรือไม่

    - `All` ตัดการเชื่อมต่อทุก AP ที่เครื่องตรวจพบ
    - `Mass` ตัดการเชื่อมต่อหลาย AP ต่อเนื่อง
    - `Selected AP` ตัดการเชื่อมต่อเฉพาะ AP ที่เลือกไว้
    - `Selected STA` ตัดการเชื่อมต่อเฉพาะอุปกรณ์ Client ที่เลือกไว้

    **ผลที่เกิดขึ้น:** อุปกรณ์จะหลุดจาก Wi‑Fi ทันที และพยายามเชื่อมต่อใหม่โดยอัตโนมัติ
  </Accordion>
  <Accordion title="Whitelist — ยกเว้นอุปกรณ์ที่เลือก" icon="shield-check">
    ใช้ `Selected STA` เป็นอุปกรณ์ที่**ไม่ต้องการโจมตี** ระหว่างการทดสอบ Deauth ฟีเจอร์อื่น อุปกรณ์ที่อยู่ใน Whitelist จะไม่ถูกตัดการเชื่อมต่อ

    **เหมาะสำหรับ:** ทดสอบเครือข่ายที่มีหลายอุปกรณ์ แต่ต้องการให้อุปกรณ์สำคัญยังเชื่อมต่ออยู่
  </Accordion>
  <Accordion title="Beacon Spam — สร้างชื่อ Wi‑Fi ปลอมจำนวนมาก" icon="radio-tower">
    สร้าง Beacon Frame จำลองชื่อเครือข่าย Wi‑Fi ปลอมหลายสิบ–หลายร้อยชื่อในเวลาเดียวกัน ใช้ทดสอบว่าโทรศัพท์หรืออุปกรณ์แสดงรายการ Wi‑Fi ได้ปกติหรือไม่เมื่อมีเครือข่ายมากเกินไป

    - `All` ใช้ชื่อจาก AP ที่เคยสแกนพบ
    - `Selected AP` ใช้ชื่อจาก AP ที่เลือกไว้
    - `Random` สร้างชื่อแบบสุ่มใหม่
    - `Prefix` กำหนดข้อความนำหน้า (เช่น `TEST_001`, `TEST_002`)

    **ผลที่เกิดขึ้น:** หน้าจอรายการ Wi‑Fi จะเต็มไปด้วยชื่อเครือข่ายปลอม
  </Accordion>
  <Accordion title="Handshake — จับข้อมูล Handshake บันทึกเป็น PCAP" icon="handshake">
    ดักจับและบันทึก **4-Way Handshake Packet** (ข้อมูลที่ส่งตอนอุปกรณ์เชื่อมต่อ Wi‑Fi) ลง Storage เป็นไฟล์ `.pcap` ใช้สำหรับการวิเคราะห์ความปลอดภัยของรหัสผ่าน Wi‑Fi

    - `Auto Active` ตัดการเชื่อมต่อ + จับ Handshake โดยอัตโนมัติ
    - `Selected AP` จับเฉพาะ AP ที่เลือกไว้

    **คำเตือน:** ตรวจพื้นที่ว่างก่อนเริ่ม และ**ห้ามเผยแพร่ไฟล์** PCAP จากเครือข่ายที่ไม่ใช่ของคุณ
  </Accordion>
  <Accordion title="Evil Portal — สร้าง Wi‑Fi ปลอมพร้อมหน้าเว็บล็อกอิน" icon="panel-top">
    สร้าง Access Point ปลอมพร้อมหน้าเว็บล็อกอินจำลอง เพื่อทดสอบว่าผู้ใช้สามารถแยกหน้าเว็บปลอมออกจากของจริงได้หรือไม่ **ใช้ใน Lab ส่วนตัวเท่านั้น**

    - `Default` ใช้ Template ที่มีให้ในเครื่อง (Google, Facebook, TikTok ฯลฯ)
    - `Selected AP` ใช้ชื่อ AP ที่เลือกไว้ร่วมกับ Template เฉพาะผู้ให้บริการไทย

    **ผลที่เกิดขึ้น:** เมื่ออุปกรณ์ทดสอบเชื่อมต่อ Wi‑Fi จะเปิดหน้าเว็บจำลองขึ้นมาอัตโนมัติ

    **คำเตือน:** ห้ามเก็บหรือเผยแพร่รหัสผ่านและข้อมูลส่วนตัวของผู้อื่น ใช้ข้อมูลตัวอย่างเท่านั้น
  </Accordion>
  <Accordion title="Auth Overload — ส่งคำขอยืนยันตัวตนล้น" icon="activity">
    ส่ง **Authentication Request** จำนวนมากไปยัง AP พร้อมกัน เพื่อทดสอบว่า Router จัดการกับคำขอที่มากเกินไปได้หรือไม่ เลือกได้ระหว่าง `All` และ `Selected AP`

    **ผลที่อาจเกิด:** AP อาจช้าลง หรืออุปกรณ์ใหม่เชื่อมต่อไม่ได้ชั่วคระหว่างทดสอบ
  </Accordion>
  <Accordion title="Assoc Overload — ส่งคำขอเชื่อมต่อล้น" icon="activity">
    ส่ง **Association Request** จำนวนมากไปยัง AP พร้อมกัน เพื่อทดสอบว่า Router รองรับอุปกรณ์เชื่อมต่อพร้อมกันได้กี่เครื่อง เลือกได้ระหว่าง `All` และ `Selected AP`

    **ผลที่อาจเกิด:** AP อาจปฏิเสธการเชื่อมต่อใหม่ หรืออุปกรณ์เดิมหลุดออกชั่วคระหว่างทดสอบ
  </Accordion>
  <Accordion title="Force CSA — บังคับเปลี่ยน Channel" icon="shuffle">
    ส่ง **Channel Switch Announcement (CSA)** เพื่อสั่งให้อุปกรณ์เปลี่ยน Channel ที่ใช้สื่อสาร ทดสอบว่าอุปกรณ์ทำตามคำสั่งหรือเพิกเฉยได้ เลือกได้เป็น `All`, `Selected AP` หรือ `Selected STA`

    **ผลที่อาจเกิด:** อุปกรณ์อาจหลุดการเชื่อมต่อชั่วคระและต้องค้นหา Channel ใหม่
  </Accordion>
  <Accordion title="DNS Repeater — ส่งต่อคำขอ DNS" icon="network">
    ทำหน้าที่เป็น DNS Server ชั่วคระ เพื่อส่งต่อคำขอแปลง Domain Name เป็น IP Address ใช้ทดสอบการทำงานของ DNS ในเครือข่ายที่คุณควบคุมได้เท่านั้น

    เริ่มจาก `WIFI → ATTACK → DNS Repeater` โดยตรง

    **เหมาะสำหรับ:** ทดสอบการตั้งค่า DNS หรือวิเคราะห์ปัญหาการเชื่อมต่ออินเทอร์เน็ต
  </Accordion>
</AccordionGroup>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** ภาพหน้า `WIFI → ATTACK` พร้อมคำอธิบายสั้น ๆ ข้างแต่ละเมนูที่มีคู่มือในหน้านี้
</Info>

## ⏹️ หยุดการทดสอบและตรวจผล

1. ใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) (กดปุ่มกลางค้าง 1 วินาที)
2. ตรวจว่าอุปกรณ์ทดสอบกลับมาเชื่อมต่อ Wi‑Fi ได้ตามปกติ
3. หาก Router หรืออุปกรณ์ยังทำงานผิดปกติ ให้รีสตาร์ทอุปกรณ์

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** วิธีหยุด ATTACK และตรวจว่าโทรศัพท์ทดสอบกลับมาเชื่อมต่อ Wi‑Fi แล้ว
</Info>

หากหน้าจอไม่ตอบสนอง ให้ดู [ฟีเจอร์ไม่หยุดหรือหน้าจอค้าง](/help/troubleshooting#ฟีเจอร์ไม่หยุดหรือหน้าจอค้าง)
