## 💡 คำแนะนำตามสถานการณ์

<AccordionGroup>
  <Accordion title="🌙 ใช้งานในห้องมืด" icon="moon">
    1. ลดความสว่างเป็น 10–25%
    2. เลือก Theme สีเข้ม (Terminal, Arctic)
    3. เปิด Mute Buzzer ถ้าต้องการเงียบ
  </Accordion>
  <Accordion title="☀️ ใช้งานกลางแจ้ง" icon="sun">
    1. เพิ่มความสว่างเป็น 75–100%
    2. เลือก Theme ที่มีคอนทราสต์สูง
    3. ปิด GIF บนหน้าจอล็อกเพื่อประหยัดแบต
  </Accordion>
  <Accordion title="🔋 ประหยัดแบตเตอรี่" icon="battery">
    1. ลดความสว่างเป็น 25%
    2. ปิดไฟ LED (OFF LED)
    3. ตั้ง Lock Timeout สั้น ๆ (10–20 วินาที)
    4. ปิด GIF บนหน้าจอล็อก
  </Accordion>
  <Accordion title="🔒 เพิ่มความปลอดภัย" icon="shield">
    1. ตั้งรหัสผ่าน 4 ครั้ง
    2. ตั้ง Lock Timeout สั้น (10–20 วินาที)
    3. จดรหัสไว้ในที่ปลอดภัย
  </Accordion>
</AccordionGroup>
