## ⚡ ตั้งค่าด่วน

### ความสว่าง
เส้นทาง: `SETTINGS → Display UI → Brightness`

เลือก: **10%** | **25%** | **50%** | **75%** | **100%**

💡 แนะนำ 25–50% เพื่อประหยัดแบต

→ [ไปหน้า Display UI](/features/settings-display)

---

### ชุดสี (Theme)
เส้นทาง: `SETTINGS → Display UI → Theme`

มี 8 ชุด: `Default` `Terminal` `Arctic` `Sunset` `Gold` `Crimson` `Electric` `Magenta`

→ [ไปหน้า Display UI](/features/settings-display)

---

### ปิดเสียง
เส้นทาง: `SETTINGS → Notification → Mute Buzzer`

เปิดตัวเลือกนี้เพื่อปิดเสียงทั้งหมด

→ [ไปหน้า Notification](/features/settings-notification)

---

### ตั้งรหัสผ่าน
เส้นทาง: `SETTINGS → Security → Set Password`

สร้างรูปแบบการกด 4 ครั้ง

→ [ไปหน้า Security](/features/settings-security)

## 💡 คำแนะนำตามสถานการณ์

<AccordionGroup>
  <Accordion title="🌙 ใช้งานในห้องมืด" icon="moon">
    1. ลดความสว่างเป็น 10–25%
    2. เลือก Theme สีเข้ม (Terminal, Arctic)
    3. เปิด Mute Buzzer ถ้าต้องการเงียบ
  </Accordion>
  <Accordion title="☀️ ใช้งานกลางแจ้ง" icon="sun">
    1. เพิ่มความสว่างเป็น 75–100%
    2. เลือก Theme ที่มีคอนทราสต์สูง
    3. ปิด GIF บนหน้าจอล็อกเพื่อประหยัดแบต
  </Accordion>
  <Accordion title="🔋 ประหยัดแบตเตอรี่" icon="battery">
    1. ลดความสว่างเป็น 25%
    2. ปิดไฟ LED (OFF LED)
    3. ตั้ง Lock Timeout สั้น ๆ (10–20 วินาที)
    4. ปิด GIF บนหน้าจอล็อก
  </Accordion>
  <Accordion title="🔒 เพิ่มความปลอดภัย" icon="shield">
    1. ตั้งรหัสผ่าน 4 ครั้ง
    2. ตั้ง Lock Timeout สั้น (10–20 วินาที)
    3. จดรหัสไว้ในที่ปลอดภัย
  </Accordion>
</AccordionGroup>
