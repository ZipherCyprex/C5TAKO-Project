## 🧩 เริ่มเล่น MAZE

```text
GAME → MAZE
```

1. เปิด `GAME → MAZE`
2. ใช้ปุ่มขึ้น/ลง/ซ้าย/ขวาเพื่อบังคับตัวละคร
3. เดินตามทางในเขาวงกตจนถึงจุดหมาย
4. เมื่อต้องการออก ใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน)

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** MAZE ไม่เกิน 15 วินาที แสดงการบังคับ การถึงจุดหมาย และการกดกลางค้างเพื่อออก
</Info>

## 🦖 เริ่มเล่น DINO

1. เปิด `GAME → DINO`
2. กดปุ่มตามคำใบ้บนหน้าจอเพื่อกระโดดหลบสิ่งกีดขวาง
3. เมื่อต้องการออก ใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน)
