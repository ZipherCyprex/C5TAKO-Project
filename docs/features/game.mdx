C5TAKO มีเกม `MAZE` สำหรับเล่นบนหน้าจอเครื่อง

## 🧩 เริ่มเล่น MAZE

```text
GAME → MAZE
```

- ใช้ขึ้น/ลง/ซ้าย/ขวาเพื่อบังคับ
- เดินไปตามทางในเขาวงกตจนถึงจุดหมาย
- เมื่อต้องการออก ใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน)

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** MAZE ไม่เกิน 15 วินาที แสดงการบังคับ การถึงจุดหมาย และการกดกลางค้างเพื่อออก
</Info>
