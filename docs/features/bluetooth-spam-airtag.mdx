หน้านี้ช่วยให้คุณทดสอบการแจ้งเตือน BLE กับโทรศัพท์ของคุณเอง

เส้นทางเมนู: `Bluetooth → SPAM`

<Warning>

ทดสอบในพื้นที่ควบคุมและหยุดทันทีเมื่อเสร็จ เพราะอุปกรณ์ของบุคคลอื่นที่อยู่ใกล้อาจได้รับการแจ้งเตือนด้วย

</Warning>

## เริ่มและหยุด

<Steps>
  <Step title="เตรียมโทรศัพท์ทดสอบ">
    วางโทรศัพท์ของคุณใกล้ C5TAKO™ และเปิด Bluetooth
  </Step>
  <Step title="เลือก Preset">
    เข้า `Bluetooth → SPAM` แล้วเลือกชื่อให้ตรงกับอุปกรณ์
  </Step>
  <Step title="เริ่มทดสอบ">
    กดกลางเพื่อเริ่ม แล้วดูการตอบสนองบนโทรศัพท์ของคุณ
  </Step>
  <Step title="หยุด">
    ทำตาม [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) ทันทีเมื่อเสร็จ
  </Step>
</Steps>
