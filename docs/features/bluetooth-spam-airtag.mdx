หน้านี้ช่วยให้คุณทดสอบการแจ้งเตือน BLE กับโทรศัพท์ของคุณเอง

เส้นทางเมนู: `Bluetooth → SPAM`

<Warning>

ทดสอบในพื้นที่ควบคุมและหยุดทันทีเมื่อเสร็จ เพราะอุปกรณ์ของบุคคลอื่นที่อยู่ใกล้อาจได้รับการแจ้งเตือนด้วย

</Warning>

## เลือก Preset

เลือกชื่อให้ตรงกับอุปกรณ์ทดสอบ:

| Preset | ใช้กับ |
| --- | --- |
| `iOS` | อุปกรณ์ Apple ที่รองรับ |
| `Samsung` | อุปกรณ์ Samsung ที่รองรับ |
| `Android` | อุปกรณ์ Android ที่รองรับ |
| `Microsoft` | อุปกรณ์ Microsoft ที่รองรับ |
| `Random` | สลับข้อมูลหลายรูปแบบ |

## เริ่มและหยุด

<Steps>
  <Step title="เตรียมโทรศัพท์ทดสอบ">
    วางโทรศัพท์ของคุณใกล้ C5TAKO™ และเปิด Bluetooth
  </Step>
  <Step title="เลือก Preset">
    เข้า `Bluetooth → SPAM` แล้วเลือกชื่อให้ตรงกับอุปกรณ์
  </Step>
  <Step title="เริ่มทดสอบ">
    กดกลางเพื่อเริ่ม แล้วดูการตอบสนองบนโทรศัพท์ของคุณ
  </Step>
  <Step title="หยุด">
    ทำตาม [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) ทันทีเมื่อเสร็จ
  </Step>
</Steps>

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** “เลือก Preset → เริ่ม → โทรศัพท์ทดสอบตอบสนอง → กดกลางค้างเพื่อหยุด” โดยไม่ให้อุปกรณ์บุคคลอื่นอยู่ในพื้นที่
</Info>

หากโทรศัพท์ไม่ตอบสนอง ให้ทำตาม [ขั้นตอนตรวจ Bluetooth](/features/bluetooth-overview#ถ้าโทรศัพท์ไม่ตอบสนอง)
