## 💡 เคล็ดลับการใช้งาน

<Tip>

**ประหยัดแบตเตอรี่:** 
- ลดความสว่างเป็น 25–50%
- ปิด GIF บนหน้าจอล็อก
- ตั้ง Timeout สั้น ๆ

**ใช้งานกลางแจ้ง:**
- เพิ่มความสว่างเป็น 75–100%
- เลือก Theme ที่มีคอนทราสต์สูง (Terminal, Arctic)

**ปรับแต่งส่วนตัว:**
- เลือก Theme ที่ชอบ
- ใส่รูป GIF หรือภาพเปิดเครื่องของคุณเอง

</Tip>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** Grid เปรียบเทียบ Theme ทั้ง 8 แบบบนหน้าจอเดียวกัน
</Info>
