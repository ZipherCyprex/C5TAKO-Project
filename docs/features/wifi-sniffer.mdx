หน้านี้ช่วยให้คุณใช้ `SNIFFER` เพื่อดู Packet สัญญาณรบกวน และอุปกรณ์ที่กำลังค้นหา Wi‑Fi รวมถึงบันทึกข้อมูลเป็นไฟล์ PCAP

<Info>

หน้านี้แสดงข้อมูลเพื่อการตรวจสอบ ไม่ได้แปลว่าอุปกรณ์ทุกชิ้นที่พบเป็นภัยคุกคาม ควรเปรียบเทียบกับสภาพแวดล้อมจริงเสมอ

</Info>

## 📦 Packet Monitor

```text
WIFI → SNIFFER → Packet Monitor
```

<AccordionGroup>
  <Accordion title="ดู Packet ทั้งหมด" icon="list-filter">
    `Monitor All` แสดง Packet ที่ตรวจพบแบบรวม โดยไม่บันทึกเป็นไฟล์
  </Accordion>
  <Accordion title="ดูพร้อมบันทึกไฟล์" icon="save">
    `All + Save` แสดง Packet และบันทึกเป็นไฟล์ PCAP ตรวจพื้นที่ว่างก่อนเริ่มที่ [FILES → File Explorer](/features/files#file-explorer)
  </Accordion>
  <Accordion title="กรองตามประเภท" icon="filter">
    เลือก `Deauth`, `Beacon`, `Probe`, `Auth`, `Client`, `EAPOL` หรือ `Action Monitor` เมื่อต้องการดูเฉพาะ Packet ประเภทนั้น
  </Accordion>
  <Accordion title="ดู Water Fall" icon="chart-spline">
    `Water Fall` แสดงกิจกรรม Wi‑Fi แบบภาพตามเวลา
  </Accordion>
</AccordionGroup>

## 💾 บันทึก PCAP แบบทีละขั้น

<Steps>
  <Step title="ตรวจพื้นที่ว่าง">
    เปิด `FILES → File Explorer` หากต้องบันทึกนาน แนะนำให้ใส่ microSD ที่รองรับก่อน
  </Step>
  <Step title="เริ่มบันทึก">
    เข้า `WIFI → SNIFFER → Packet Monitor → All + Save`
  </Step>
  <Step title="รอเก็บข้อมูล">
    ปล่อยให้เครื่องทำงานเฉพาะช่วงที่ต้องการ หลีกเลี่ยงการบันทึกข้อมูลจากเครือข่ายที่ไม่ได้รับอนุญาต
  </Step>
  <Step title="หยุดและตรวจไฟล์">
    กดกลางค้างประมาณ 1 วินาที จากนั้นเปิด `FILES → File Explorer` เพื่อตรวจไฟล์ที่สร้างขึ้น
  </Step>
</Steps>

## 📍 Tracker และตัวตรวจจับอื่น

- `Jammer Detect` ใช้เป็นข้อมูลช่วยสังเกตเท่านั้น ผลแจ้งเตือนไม่ได้ยืนยันว่ามี Jammer เสมอไป
- `Find Hidden AP` ช่วยมองหา AP ที่ซ่อนชื่อ แต่ผลขึ้นอยู่กับ Packet ที่พบในขณะนั้น
- `WiFi Tracker` ใช้ติดตาม AP
- `STA Tracker` ใช้ติดตาม Client

</Note>
