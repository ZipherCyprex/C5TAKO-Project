ใช้ `SCAN` เมื่อต้องการดูว่าเครื่องมองเห็น Router และอุปกรณ์ Wi‑Fi ใดบ้าง การเลือกเป้าหมายในหน้านี้จะถูกนำไปใช้กับเมนูที่เขียนว่า `Selected AP` หรือ `Selected STA`

## ก่อนเริ่ม

- วาง C5TAKO ใกล้เครือข่ายที่ต้องการตรวจสอบ
- ใช้เครือข่ายและอุปกรณ์ของคุณเองหรือที่ได้รับอนุญาต
- หากกำลังใช้ฟีเจอร์ Wi‑Fi อื่น ให้หยุดก่อนเริ่ม Scan

## 📡 AP — Router หรือ Access Point

เส้นทางเมนู:

```text
WIFI → SCAN → AP → Scan
```

<Steps>
  <Step title="เริ่มสแกน">
    เข้า `WIFI → SCAN → AP → Scan` แล้วรอจนรายการเครือข่ายปรากฏ
  </Step>
  <Step title="เปิดรายการที่ค้นพบ">
    เข้า `WIFI → SCAN → AP → Select` แล้วใช้ขึ้น/ลงเลื่อนดูชื่อเครือข่าย
  </Step>
  <Step title="เลือก AP">
    กดกลางที่เครือข่ายที่ต้องการ เมื่อเลือกสำเร็จ หน้าจอจะใช้ AP นี้กับคำสั่ง `Selected AP`
  </Step>
  <Step title="ตรวจข้อมูล">
    เข้า `WIFI → SCAN → AP → Info` เพื่อดูข้อมูลของ AP ที่เลือก
  </Step>
</Steps>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** ภาพหน้าผล Scan AP พร้อมวงตำแหน่งชื่อเครือข่าย สัญญาณ และรายการที่ถูกเลือก โดยใช้เครือข่ายทดสอบ
</Info>

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** “Scan AP → Select → เลือกรายการ → Info → ย้อนกลับ” และเบลอชื่อเครือข่ายจริง
</Info>

## 📱 STA — โทรศัพท์หรือ Client

เส้นทางเมนู:

```text
WIFI → SCAN → STA → Scan
```

ขั้นตอนเหมือนการสแกน AP:

1. เลือก `Scan` และรอให้ค้นหาเสร็จ
2. เข้า `Select` เพื่อเลือกอุปกรณ์
3. เข้า `Info` เพื่อดูข้อมูลอุปกรณ์ที่เลือก

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** “Scan STA → Select → Info” โดยใช้อุปกรณ์ของผู้ถ่ายเองและเบลอ Address ก่อนเผยแพร่
</Info>

## 🔄 Scan AP+STA

```text
WIFI → SCAN → Scan AP+STA
```

เลือกเมนูนี้เมื่อต้องการค้นหาทั้ง Router และอุปกรณ์ในรอบเดียว เหมาะกับการดูภาพรวมก่อนเริ่มทดสอบ

## ✅ เช็กว่าเลือกสำเร็จหรือยัง

เปิด `AP → Info` หรือ `STA → Info` หากหน้าจอแสดงข้อมูลของรายการที่ต้องการ แสดงว่าเลือกสำเร็จแล้ว

<Tip>

ถ้าไม่พบรายการ ให้ขยับเข้าใกล้อุปกรณ์ รอให้การสแกนเดิมจบ แล้วลองใหม่อีกครั้ง

</Tip>
