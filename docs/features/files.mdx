หน้านี้ช่วยให้คุณดู เปลี่ยนชื่อ ลบไฟล์ และจัดการพื้นที่เก็บข้อมูลของ C5TAKO™

เครื่องมีพื้นที่ไฟล์ภายใน **4MB** และรองรับ microSD เพิ่มเติม แต่ไม่มีการ์ดแถมในกล่อง

## 📂 File Explorer

```text
FILES → File Explorer
```

เปิดหน้านี้เพื่อดูไฟล์และตรวจพื้นที่เก็บข้อมูล เมื่อเลือกไฟล์จะพบคำสั่งเหล่านี้:

<CardGroup cols={2}>
  <Card title="Read" icon="file-text">
    เปิดดูข้อมูลในไฟล์
  </Card>
  <Card title="Rename" icon="pencil">
    เปลี่ยนชื่อไฟล์
  </Card>
  <Card title="Delete" icon="trash-2">
    ลบไฟล์ที่เลือก
  </Card>
  <Card title="Crack" icon="key">
    แสดงเฉพาะไฟล์ PCAP ที่เครื่องรองรับ
  </Card>
</CardGroup>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** ภาพ File Explorer ที่ใช้ไฟล์ตัวอย่าง พร้อมวงตำแหน่งชื่อไฟล์ ขนาด และ Storage ที่กำลังใช้งาน
</Info>

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** “เปิด File Explorer → เลือกไฟล์ตัวอย่าง → Read → Rename → ย้อนกลับ” โดยไม่ใช้ข้อมูลจริงจากเครือข่าย
</Info>

### ลบไฟล์เดียว

1. เลือกไฟล์ใน `File Explorer`
2. เลือก `Delete`
3. อ่านชื่อไฟล์อีกครั้งก่อนยืนยัน
4. เลือกยืนยันเมื่อตรวจสอบชื่อไฟล์ถูกต้องแล้ว

<Warning>

ไฟล์ที่ลบแล้วไม่สามารถเรียกคืนจากตัวเครื่องได้

</Warning>

## 🚨 Format Storage

```text
FILES → Format Storage
```

คำสั่งนี้ลบไฟล์ทั้งหมดใน Storage ที่กำลังใช้งาน ไม่ใช่เฉพาะไฟล์ที่เลือก

ตรวจชื่อ Storage ให้แน่ใจก่อนเริ่ม เพราะการ Format ย้อนกลับไม่ได้

<Steps>
  <Step title="สำรองไฟล์">
    ย้ายไฟล์สำคัญออกจาก Storage ก่อนเริ่ม
  </Step>
  <Step title="ตรวจชื่อ Storage">
    อ่านชื่อพื้นที่เก็บข้อมูลบนหน้าจอว่าเป็นพื้นที่ภายในหรือ microSD
  </Step>
  <Step title="เลือก Format Storage">
    เข้า `FILES → Format Storage`
  </Step>
  <Step title="ยืนยันหรือยกเลิก">
    เลือก `FORMAT` เมื่อแน่ใจ หรือ `Cancel` เพื่อออกโดยไม่ลบข้อมูล
  </Step>
</Steps>

<Info>
🎬 **ต้องเพิ่มคลิปตรงนี้:** ขั้นตอน Format ด้วยไฟล์ตัวอย่างเท่านั้น แสดงการตรวจชื่อ Storage และทั้งปุ่ม Cancel/FORMAT
</Info>

<Warning>

🗑️ การ Format ย้อนกลับไม่ได้ หากไม่แน่ใจให้เลือก `Cancel`

</Warning>

## ถ้า microSD ไม่แสดง

1. ปิดเครื่องก่อนถอดหรือใส่ microSD
2. ตรวจทิศทางและเสียบการ์ดให้สุด
3. เปิดเครื่องแล้วตรวจใน `FILES → File Explorer`
4. ลองการ์ดอีกใบที่ไม่มีข้อมูลสำคัญ
5. ตรวจพื้นที่ว่างก่อนเริ่มบันทึก

หากยังมองไม่เห็น Storage ให้ดู [วิธีแก้ปัญหา](/help/troubleshooting#storage-หรือ-microsd-มีปัญหา)
