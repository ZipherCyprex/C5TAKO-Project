เมนู `SUB-GHz` จะแสดงเมื่อเครื่องตรวจพบโมดูล **CC1101** เท่านั้น ใช้กับอุปกรณ์และความถี่ที่คุณเป็นเจ้าของหรือได้รับอนุญาต และตรวจข้อกำหนดคลื่นความถี่ในพื้นที่ก่อนส่งสัญญาณ

<Warning>

การรบกวน การดักรับ หรือการส่งซ้ำสัญญาณโดยไม่ได้รับอนุญาตอาจผิดกฎหมาย ใช้ในสภาพแวดล้อมทดสอบที่ควบคุมได้เท่านั้น

</Warning>
