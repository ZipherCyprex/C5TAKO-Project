หน้านี้ช่วยให้คุณดูอุปกรณ์ BLE ที่กำลังส่งข้อมูลประกาศอยู่ใกล้ C5TAKO™ และเปิดรายละเอียดของอุปกรณ์แต่ละรายการ

## 📊 BLE Monitor

```text
Bluetooth → SNIFFER → BLE Monitor
```

ใช้ดูข้อมูล BLE Advertisement ที่เครื่องตรวจพบ เหมาะกับการเช็กว่าบริเวณนั้นมีการส่งสัญญาณ BLE มากน้อยเพียงใด

1. เปิด `Bluetooth → SNIFFER → BLE Monitor`
2. รอให้รายการอุปกรณ์แสดงบนหน้าจอ
3. กดกลางค้างประมาณ 1 วินาทีเมื่อต้องการหยุด

## 🔎 Inspector

```text
Bluetooth → SNIFFER → Inspector
```

ใช้เปิดดูรายการและรายละเอียดของอุปกรณ์ BLE ที่ตรวจพบ เหมาะเมื่อต้องการแยกดูอุปกรณ์ทีละรายการ

1. เปิด `Bluetooth → SNIFFER → Inspector`
2. เลือกรายการอุปกรณ์ที่ต้องการดู
3. อ่านรายละเอียดบนหน้าจอ
4. กดซ้ายเพื่อย้อนกลับ หรือใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) เพื่อออกจากหน้าทำงาน

<Info>

ชื่อหรือ Address ที่เห็นอาจไม่บอกเจ้าของหรือชนิดอุปกรณ์ได้แน่นอน และอุปกรณ์บางชนิดเปลี่ยน Address อัตโนมัติเพื่อความเป็นส่วนตัว

</Info>

## ถ้าหาอุปกรณ์ไม่เจอ

1. วางอุปกรณ์ให้ใกล้ C5TAKO™ มากขึ้น
2. ตรวจว่าอุปกรณ์กำลังเปิด Bluetooth และอยู่ในสถานะที่ส่งสัญญาณ
3. ใช้ [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) เพื่อปิดหน้าสแกนเดิม
4. ปิด–เปิด Bluetooth ของอุปกรณ์ทดสอบ แล้วเริ่มใหม่
5. หากยังไม่พบ ให้ปิด–เปิด C5TAKO™
