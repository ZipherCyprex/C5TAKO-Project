### 📝 ข้อมูลที่แสดง

เมื่อเข้าหน้า Info จะเห็นข้อมูลเหล่านี้:

<AccordionGroup>
  <Accordion title="Firmware Information" icon="code">
    - **Version**: เวอร์ชัน Firmware
    - **Build Date**: วันที่สร้าง Firmware
    - **Board**: ชื่อบอร์ด (เช่น `XIAO ESP32-C5`)
  </Accordion>
  <Accordion title="Hardware Information" icon="cpu">
    - **Flash Size**: ขนาด Flash memory
    - **Free Heap**: หน่วยความจำว่างในขณะนั้น
    - **Chip Model**: รุ่นของชิป
  </Accordion>
  <Accordion title="Network Information" icon="network">
    - **Wi-Fi MAC**: MAC Address ของ Wi-Fi
    - **BT MAC**: MAC Address ของ Bluetooth
    - **Status**: สถานะการทำงานของ Module
  </Accordion>
  <Accordion title="Storage Information" icon="folder">
    - **Internal**: พื้นที่ภายใน (ใช้/ทั้งหมด)
    - **SD Card**: พื้นที่ microSD (ถ้ามี)
    - **Free Space**: พื้นที่ว่างที่เหลือ
  </Accordion>
</AccordionGroup>

<Info>

**เมื่อไหร่ต้องดูข้อมูล Info:**
- ก่อนอัปเดต Firmware (เช็กเวอร์ชันเดิม)
- เมื่อต้องการแจ้งปัญหาให้ฝ่ายช่วยเหลือ
- ตรวจสอบพื้นที่ว่างก่อนบันทึกไฟล์
- ดู MAC Address สำหรับการตั้งค่าเครือข่าย

</Info>

## 🔄 เริ่มระบบใหม่ (Reboot)

<Warning>

**ก่อน Reboot:**
- บันทึกงานที่กำลังทำอยู่
- หยุดฟีเจอร์ที่กำลังทำงาน
- ตรวจว่าไม่มีไฟล์กำลัง Transfer อยู่

</Warning>

### เมื่อไหร่ควร Reboot?

<CardGroup cols={2}>
  <Card title="🐛 หน้าจอผิดปกติ" icon="monitor-x">
    หน้าจอค้าง แสดงผลผิด หรือกะพริบ
  </Card>
  <Card title="🔌 Bluetooth/Wi-Fi ไม่ทำงาน" icon="wifi-off">
    เชื่อมต่อไม่ได้ หรือหาอุปกรณ์ไม่เจอ
  </Card>
  <Card title="⚠️ ฟีเจอร์ Error" icon="alert-circle">
    ฟีเจอร์บางตัวทำงานผิดปกติ
  </Card>
  <Card title="🔧 หลังเปลี่ยนการตั้งค่า" icon="settings">
    บางการตั้งค่าต้อง Reboot ถึงจะมีผล
  </Card>
</CardGroup>

### ขั้นตอน Reboot

<Steps>
  <Step title="เข้าหน้า Reboot" icon="power">
    เข้า `Device → Reboot`
  </Step>
  <Step title="ยืนยัน" icon="check-circle">
    เลือก `Reboot` เพื่อยืนยัน หรือ `Cancel` เพื่อยกเลิก
  </Step>
  <Step title="รอเปิดใหม่" icon="loader">
    เครื่องจะปิด รอประมาณ 5-10 วินาที แล้วเปิดใหม่อัตโนมัติ
  </Step>
  <Step title="ตรวจสอบ" icon="eye">
    ตรวจว่าเข้าสู่เมนูหลักได้ตามปกติ
  </Step>
</Steps>

<Note>

**Reboot vs. ปิด-เปิดเครื่อง:**
- **Reboot**: ระบบปิด-เปิดเอง รวดเร็วกว่า
- **ปิด-เปิดด้วยมือ**: กดสวิตช์ด้านข้างเอง ควรรอ 5 วินาทีก่อนเปิดใหม่

ทั้งสองวิธีให้ผลลัพธ์เหมือนกัน

</Note>

## 💡 เคล็ดลับ

<Tip>

**Screenshot ข้อมูล Info:**
- ถ่ายภาพหน้า Info ไว้เพื่อใช้อ้างอิงภายหลัง
- เก็บไว้ในที่ปลอดภัยพร้อมกับเลขคำสั่งซื้อ

**Reboot เป็นประจำ:**
- หากใช้งานหนัก ควร Reboot ทุก 1-2 สัปดาห์
- ช่วยเคลียร์หน่วยความจำและทำให้ระบบทำงานดีขึ้น

**ก่อนอัปเดต Firmware:**
- เช็กเวอร์ชันเดิมจากหน้า Info
- เปรียบเทียบว่าอัปเดตถูกเวอร์ชันหรือไม่

</Tip>

<Info>
📷 **ต้องเพิ่มรูปตรงนี้:** Screenshot หน้า Device Info และขั้นตอน Reboot
</Info>
