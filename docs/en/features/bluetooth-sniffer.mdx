View BLE devices advertising near C5TAKO™ and open the details for each device.

## 📊 BLE Monitor

```text
Bluetooth → SNIFFER → BLE Monitor
```

Use this view to see BLE advertisements detected by the device and assess how much BLE activity is present nearby.

1. Open `Bluetooth → SNIFFER → BLE Monitor`.
2. Wait for devices to appear on the display.
3. Hold the center button for about one second to stop.

## 🔎 Inspector

```text
Bluetooth → SNIFFER → Inspector
```

Use this view to inspect the detected BLE device list and details one device at a time.

1. Open `Bluetooth → SNIFFER → Inspector`.
2. Select the device to inspect.
3. Read the details on the display.
4. Press left to go back, or use [the feature-stop procedure](/en/getting-started/controls#stop-an-active-feature) to leave the active screen.

<Info>

The displayed name or address may not reliably identify an owner or device type. Some devices automatically rotate their address for privacy.

</Info>

## If no devices are found

1. Move the device closer to C5TAKO™.
2. Confirm that Bluetooth is enabled and the device is advertising.
3. Use [the feature-stop procedure](/en/getting-started/controls#stop-an-active-feature) to close the current scan screen.
4. Turn Bluetooth off and on again on the test device, then retry.
5. If it is still not found, restart C5TAKO™.
