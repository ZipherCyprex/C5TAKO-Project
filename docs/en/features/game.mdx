This page explains how to start and exit `MAZE`.

## 🧩 Play MAZE

```text
GAME → MAZE
```

1. Open `GAME → MAZE`.
2. Use up, down, left, and right to control the character.
3. Follow the maze path to the goal.
4. To exit, use [the feature-stop procedure](/en/getting-started/controls#stop-an-active-feature).
