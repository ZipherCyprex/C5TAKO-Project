## ⚡ Quick Settings

### Brightness
Path: `SETTINGS → Display UI → Brightness`

Choose: **10%** | **25%** | **50%** | **75%** | **100%**

💡 Recommended 25–50% to save battery

→ [Go to Display UI](/en/features/settings-display)

---

### Theme - Color Scheme
Path: `SETTINGS → Display UI → Theme`

8 themes: `Default` `Terminal` `Arctic` `Sunset` `Gold` `Crimson` `Electric` `Magenta`

→ [Go to Display UI](/en/features/settings-display)

---

### Mute Sound
Path: `SETTINGS → Notification → Mute Buzzer`

Enable this option to mute all sounds

→ [Go to Notification](/en/features/settings-notification)

---

### Set Password
Path: `SETTINGS → Security → Set Password`

Create a 4-press pattern

→ [Go to Security](/en/features/settings-security)

## 💡 Recommendations by Situation

<AccordionGroup>
  <Accordion title="🌙 Use in Dark Room" icon="moon">
    1. Reduce brightness to 10–25%
    2. Choose dark Theme (Terminal, Arctic)
    3. Enable Mute Buzzer if you need silence
  </Accordion>
  <Accordion title="☀️ Outdoor Use" icon="sun">
    1. Increase brightness to 75–100%
    2. Choose high-contrast Theme
    3. Turn off GIF on lock screen to save battery
  </Accordion>
  <Accordion title="🔋 Save Battery" icon="battery">
    1. Reduce brightness to 25%
    2. Turn off LED (OFF LED)
    3. Set short Lock Timeout (10–20 seconds)
    4. Turn off GIF on lock screen
  </Accordion>
  <Accordion title="🔒 Increase Security" icon="shield">
    1. Set 4-press password
    2. Set short Lock Timeout (10–20 seconds)
    3. Write down password in a safe place
  </Accordion>
</AccordionGroup>
