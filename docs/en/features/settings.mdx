Configure sound, lights, display, password, and device information. For a new device, start with the [initial settings checklist](/en/getting-started/first-settings).

| What to change | Menu path |
| --- | --- |
| Sound and status light | [`SETTINGS → Notification`](#notification) |
| Lock screen, brightness, boot image, and theme | [`SETTINGS → Display UI`](#display-ui) |
| Password | [`SETTINGS → Security`](#security) |
| Device information or restart | [`SETTINGS → Device`](#device) |

## 🔔 Notification

Menu path: `SETTINGS → Notification`

- `Mute Buzzer` turns notification sound off or on. Enable this option to mute it.
- `OFF LED` turns the status LED off or on. Enable this option to turn it off.
- `Test Buzzer` previews each sound pattern.
- `Test LED` tests the status light.

<Info>

`Mute` and `OFF` mean “disabled,” so their wording can look opposite to the on-screen switch state.

</Info>

## 🎨 Display UI

Menu path: `SETTINGS → Display UI`

<AccordionGroup>
  <Accordion title="Lock screen" icon="lock">
    - `Timeout`: choose 10–60 seconds before locking, or `Disable` to turn the lock screen off.
    - `Lock dim`: set brightness while locked.
    - `GIF path`: choose the GIF file path.
    - `GIF image`: enable or disable the GIF.
    - `Boomerang`: play the GIF forward and backward.
  </Accordion>
  <Accordion title="Booting" icon="power">
    - `Custom image`: enable or disable a user-provided image.
    - `Image path`: choose the image file path.
  </Accordion>
  <Accordion title="Brightness" icon="sun">
    Open `SETTINGS → Display UI → Brightness` and choose `10%`, `25%`, `50%`, `75%`, or `100%`. Start at 25–50% to conserve battery.
  </Accordion>
  <Accordion title="Theme" icon="palette">
    Open `SETTINGS → Display UI → Theme` and choose `Default`, `Terminal`, `Arctic`, `Sunset`, `Gold`, `Crimson`, `Electric`, or `Magenta`. The active theme has a trailing `*`.
  </Accordion>
</AccordionGroup>

## 🔐 Security

Menu path: `SETTINGS → Security`

The password is a sequence of four presses using up, down, left, right, and/or the center button.

<Steps>
  <Step title="Open password settings">
    Open `SETTINGS → Security → Set Password`.
  </Step>
  <Step title="Create a pattern">
    Enter four directional or center-button presses and remember their order.
  </Step>
  <Step title="Confirm">
    When the device asks `Use this pattern?`, select `Use` to save it or `Retry` to try again.
  </Step>
</Steps>

<Info>
🎬 **Media to add:** A sample password-pattern setup, omitting the recorder's real password.
</Info>

After setting a password:

- Use `Reset Password` to change the pattern.
- Use `Disable Password` to remove the password.
- If you forget it, see [forgotten-password troubleshooting](/en/help/troubleshooting#forgotten-password).

## ℹ️ Device

Menu path: `SETTINGS → Device`

- `Info` displays Firmware, Flash, Wi-Fi, Bluetooth, and Storage information.
- `Reboot` restarts the device when the display or a feature behaves unexpectedly but menus remain accessible.

For details to send to support, see [what to provide when contacting support](/en/help/troubleshooting#what-to-provide-when-contacting-support).
