Names in `code` match the device labels. Select the same name to open the related guide.

## 🧭 Device menus

<CardGroup cols={2}>
  <Card title="WIFI" icon="wifi" href="/en/features/wifi-overview">
    Discover, inspect, and test Wi-Fi networks
  </Card>
  <Card title="Bluetooth" icon="bluetooth" href="/en/features/bluetooth-overview">
    View and test BLE devices
  </Card>
  <Card title="SUB-GHz" icon="radio" href="/en/features/sub-ghz">
    Appears when the device detects a CC1101 module
  </Card>
  <Card title="APP" icon="panels-top-left" href="/en/features/apps">
    Use Buzzer, Flashlight, MAP, and NMAP
  </Card>
  <Card title="GAME" icon="gamepad-2" href="/en/features/game">
    Play MAZE and DINO
  </Card>
  <Card title="FILES" icon="folder-open" href="/en/features/files">
    Manage files, Web Files, and storage
  </Card>
  <Card title="SETTINGS" icon="settings" href="/en/features/settings">
    Configure notifications, display, security, and device options
  </Card>
</CardGroup>

<Tip>

A path such as `WIFI → SCAN → AP → Scan` means choosing each label from left to right. See [how to read a menu path](/en/getting-started/controls#read-a-menu-path).

</Tip>

![C5TAKO™ main menu](/images/device/main-menu.jpeg)

<Note>

`SUB-GHz` appears only when a CC1101 is detected, so it may not be visible in the photo.

</Note>
