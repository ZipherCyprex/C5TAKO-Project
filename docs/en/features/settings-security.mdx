This page helps you manage passwords to prevent unauthorized device access

## 🔐 About Password

C5TAKO™ password is a **4-press pattern** using:
- ⬆️ Up
- ⬇️ Down
- ⬅️ Left
- ➡️ Right
- ⭕ Center press

Mix freely, e.g.: Up → Right → Center → Down

---

## 🆕 Set Password First Time

<Steps>
  <Step title="Open password settings" icon="lock-open">
    Open `Security → Set Password`
  </Step>
  <Step title="Create a pattern" icon="hand-pointing">
    Press directions or center button for a total of **4 presses**
    
    <Warning>
    
    **Remember the sequence!** If you forget, you may need to contact the seller to reset
    
    </Warning>
  </Step>
  <Step title="Confirm" icon="check-circle">
    When the screen asks `Use this pattern?`
    - Select `Use` to save
    - Select `Retry` to try again
  </Step>
  <Step title="Test" icon="shield-check">
    Lock the device and try unlocking with your password
    
    If successful, you're all set!
  </Step>
</Steps>

## 🔄 Change Password

Once a password is set, you can change it:

<Steps>
  <Step title="Open Reset page" icon="rotate-ccw">
    Open `Security → Reset Password`
  </Step>
  <Step title="Enter current password" icon="unlock">
    Press your current password to verify identity
  </Step>
  <Step title="Create new password" icon="lock">
    Press a new 4-press pattern and confirm
  </Step>
</Steps>

---

## 🔓 Disable Password

If you no longer want to use a password:

<Steps>
  <Step title="Open Disable page" icon="lock-open">
    Open `Security → Disable Password`
  </Step>
  <Step title="Confirm" icon="unlock">
    Press your current password to verify
  </Step>
  <Step title="Disable" icon="check">
    Select confirm to disable password
  </Step>
</Steps>

<Note>

After disabling the password, the device will not lock. You can re-enable it anytime

</Note>

---

## 🆘 If You Forget Password

<Warning>

**Cannot reset yourself!** If you forget your password:

1. **Stop trying** - Repeatedly entering wrong passwords won't help
2. **Contact seller** - Provide purchase date and order number
3. **Prepare data** - Reset may affect settings or Storage data

</Warning>

See details at [Forgotten password troubleshooting](/en/help/troubleshooting#forgotten-password)

## 💡 Security Tips

<Tip>

**Create memorable password:**
- Use a pattern related to you but hard for others to guess
- Avoid simple patterns like Up → Up → Up → Up
- Don't use the same pattern as other devices

**Write down safely:**
- Write on paper and keep in wallet
- Save in password manager app
- Don't store in phone photos

**Test before committing:**
- After setting, test lock-unlock several times
- Make sure you remember before leaving this page

</Tip>
