View, rename, and delete files, and manage C5TAKO™ storage.

The device has **4 MB** of internal file storage and supports additional microSD storage. A card is not included.

## 📂 File Explorer

```text
FILES → File Explorer
```

Open this page to view files and check storage. Selecting a file offers these commands:

| Device command | Purpose |
| --- | --- |
| `Read` | Open the file's contents. |
| `Rename` | Rename the file. |
| `Delete` | Delete the selected file. |
| `Crack` | Show only supported PCAP files. |

### Delete one file

1. Select a file in `File Explorer`.
2. Select `Delete`.
3. Read the filename again before confirming.
4. Confirm only when the filename is correct.

<Warning>

Files deleted from the device cannot be recovered.

</Warning>

## 🚨 Format Storage

```text
FILES → Format Storage
```

This command deletes **all** files in the active storage, not only the selected file.

Verify the storage name before starting: formatting cannot be undone.

<Steps>
  <Step title="Back up files">
    Move important files out of the storage before starting.
  </Step>
  <Step title="Check the storage name">
    Confirm on-screen whether the storage is internal or microSD.
  </Step>
  <Step title="Choose Format Storage">
    Open `FILES → Format Storage`.
  </Step>
  <Step title="Confirm or cancel">
    Select `FORMAT` only when certain, or `Cancel` to leave data untouched.
  </Step>
</Steps>

## If microSD does not appear

1. Turn the device off before removing or inserting a microSD card.
2. Check its orientation and insert it fully.
3. Turn the device on and check `FILES → File Explorer`.
4. Try another card that contains no important data.
5. Check free space before beginning a recording.

If storage still does not appear, see [troubleshooting](/en/help/troubleshooting#storage-or-microsd-problems).
