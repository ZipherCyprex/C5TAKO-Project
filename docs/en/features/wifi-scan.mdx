Find Wi-Fi routers and devices, then select the target required by menus labeled `Selected AP` or `Selected STA`.

## Before you begin

- Place C5TAKO™ near the network you need to inspect.
- Use only your own networks and devices, or ones you are authorized to use.
- Stop any other Wi-Fi feature before starting a scan.

## 📡 AP — Router or Access Point

```text
WIFI → SCAN → AP → Scan
```

<Steps>
  <Step title="Start scanning">
    Open `WIFI → SCAN → AP → Scan` and wait for the network list.
  </Step>
  <Step title="Open discovered networks">
    Open `WIFI → SCAN → AP → Select`, then use up/down to browse network names.
  </Step>
  <Step title="Select an AP">
    Press the center button on the intended network. Once selected, this AP is used by commands labeled `Selected AP`.
  </Step>
  <Step title="Check its details">
    Open `WIFI → SCAN → AP → Info` to view the selected AP.
  </Step>
</Steps>

**Confirm success:** `AP → Info` shows the selected network's information.

## 📱 STA — Phone or client

```text
WIFI → SCAN → STA → Scan
```

1. Open `WIFI → SCAN → STA → Scan`.
2. Wait for scanning to finish and for devices to appear.
3. Open `WIFI → SCAN → STA → Select`.
4. Use up/down, then press the center button on the intended device.
5. Open `WIFI → SCAN → STA → Info` to inspect the selected device.

**Confirm success:** `STA → Info` shows the selected device's information.

## 🔄 Scan AP+STA

```text
WIFI → SCAN → Scan AP+STA
```

Use this menu to find both routers and devices in one pass before beginning a test.

## ✅ Check whether selection succeeded

Open `AP → Info` or `STA → Info`. If the screen shows the intended entry's information, it was selected successfully.

<Tip>

If no entry appears, move closer to the device, let the current scan finish, and try again.

</Tip>
