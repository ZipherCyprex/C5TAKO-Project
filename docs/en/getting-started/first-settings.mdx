---

After confirming that the device and controls work, configure these three items first. You can adjust everything else later.

<Steps>
  <Step title="Set a password">
    Open `SETTINGS → Security → Set Password` and create a four-press pattern. See [set, change, or remove a password](/en/features/settings#security).
  </Step>
  <Step title="Choose a theme">
    Open `SETTINGS → Display UI → Theme` and select a color theme. See [display settings](/en/features/settings#display-ui).
  </Step>
  <Step title="Adjust brightness">
    Open `SETTINGS → Display UI → Brightness`, start at 25–50%, then adjust for the lighting. See [display settings](/en/features/settings#display-ui).
  </Step>
</Steps>

<Warning>

The password is a four-press pattern. Store its sequence securely; if you forget it, you may need to contact the seller for help.

</Warning>

When done, continue to [choose a feature](/en/features/menu-overview).
