C5TAKO™ uses one five-way button. Use it to select menus, go back, and stop an active feature.

## Directional controls

| Press | Usual action |
| --- | --- |
| Up / down | Move through a list. |
| Right | Open an item. |
| Short center press | Open, confirm, or start. |
| Left | Go back one level. |
| Hold center for about one second | Stop a feature or leave an active screen. |

Some screens use controls differently, such as left/right to change a value. Follow the hint at the bottom of the screen first.

## Read a menu path

An arrow `→` means “choose the next menu,” for example:

```text
SETTINGS → Display → Theme
```

1. Move to `SETTINGS`, then press right or the center button.
2. Select `Display`.
3. Select `Theme`.

You do not need to memorize paths: keep the guide open and follow each name from left to right.

## Stop an active feature

1. Hold the center button for about one second.
2. Release it when the screen stops or returns to a menu.
3. If the device still does not respond, turn its switch off, wait about five seconds, then turn it back on.

Use this procedure for scan, signal-inspection, and game screens unless an on-screen hint specifies another method.

## If a list scrolls too quickly

Holding a directional button scrolls continuously. To move one item at a time, tap and release it.
