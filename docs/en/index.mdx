C5TAKO™ is a portable Wi-Fi and Bluetooth testing device. Start from the device menu and open the guide that matches your task.

<Warning>

C5TAKO™ is **not waterproof**. Use network-testing features only with your own devices or systems you are authorized to test.

</Warning>

<Info>

⭐ **Key feature:** C5TAKO™ supports both **2.4 GHz and 5 GHz** Wi-Fi bands.

</Info>

## Choose a device menu

After powering on, select a guide by the menu name shown on the display:

| Device menu | Purpose | Guide |
| --- | --- | --- |
| `WIFI` | Scan, inspect, and test 2.4 GHz and 5 GHz Wi-Fi. | [Open WIFI guide](/en/features/wifi-overview) |
| `Bluetooth` | Inspect and test BLE devices. | [Open Bluetooth guide](/en/features/bluetooth-overview) |
| `APP` | Use sounds and the display light. | [Open APP guide](/en/features/apps) |
| `GAME` | Play `MAZE`. | [Open GAME guide](/en/features/game) |
| `FILES` | View and manage files. | [Open FILES guide](/en/features/files) |
| `SETTINGS` | Configure the device. | [Open SETTINGS guide](/en/features/settings) |
