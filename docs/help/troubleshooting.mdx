เริ่มจากหัวข้อที่ตรงกับอาการ หากต้องปิด–เปิดเครื่อง ให้รอประมาณ 5 วินาทีก่อนเปิดใหม่

## เครื่องเปิดไม่ติดหรือหน้าจอไม่ขึ้น

1. ตรวจว่าสวิตช์ด้านข้างอยู่ตำแหน่งเปิด
2. เสียบสายชาร์จและทิ้งไว้สักระยะก่อนลองใหม่
3. เปลี่ยนสาย USB และแหล่งจ่ายไฟ
4. ถอด microSD ออกชั่วคราว แล้วลองเปิดอีกครั้ง
5. ตรวจว่าพอร์ตไม่มีน้ำ ฝุ่น หรือสิ่งแปลกปลอม

<Warning>

หากเครื่องร้อนผิดปกติ มีกลิ่นไหม้ แบตเตอรี่บวม หรือเคยสัมผัสน้ำ ให้หยุดชาร์จและหยุดใช้งานทันที

</Warning>

## ปุ่มไม่ตอบสนองหรือเมนูเลื่อนเอง

- แตะปุ่มแล้วปล่อย อย่ากดค้างโดยไม่ตั้งใจ
- ตรวจว่าปุ่ม 5 ทิศทางไม่ติดกับขอบเคส
- ปิดเครื่องแล้วกดปุ่มเบา ๆ ทุกทิศทางเพื่อดูว่าคืนตัวหรือไม่
- เปิดเครื่องใหม่และลองที่หน้าเมนูหลัก

หากยังเลื่อนเองหรือกดทิศทางใดไม่ได้ ให้ถ่ายคลิปอาการแล้วติดต่อผู้ขาย

## ฟีเจอร์ไม่หยุดหรือหน้าจอค้าง

ทำตาม [วิธีหยุดฟีเจอร์](/getting-started/controls#หยุดฟีเจอร์ที่กำลังทำงาน) หากเกิดซ้ำกับเมนูเดิม ให้หลีกเลี่ยงเมนูนั้นชั่วคราวและเตรียมข้อมูลสำหรับติดต่อฝ่ายช่วยเหลือ

## ลืมรหัสผ่าน

หากใส่ผิด ให้รอหน้าจอพร้อมแล้วลองรูปแบบ 4 ครั้งอีกครั้งอย่างช้า ๆ หากจำไม่ได้ ให้หยุดลองและติดต่อผู้ขาย การแก้ไขอาจกระทบการตั้งค่าหรือข้อมูลใน Storage

ดูวิธีตั้ง เปลี่ยน หรือปิดรหัสที่ [SETTINGS — Security](/features/settings#security)

## Storage หรือ microSD มีปัญหา

ทำตามรายการตรวจที่ [ถ้า microSD ไม่แสดง](/features/files#ถ้า-microsd-ไม่แสดง) อย่าเลือก `Format Storage` หากยังมีไฟล์สำคัญ เพราะจะลบข้อมูลทั้งหมดใน Storage ที่กำลังใช้งาน

## เว็บอัปเดตหาเครื่องไม่เจอ

ทำตามขั้นตอนเรียงลำดับที่ [ถ้าเว็บไม่พบเครื่อง](/getting-started/update-firmware#ถ้าเว็บไม่พบเครื่อง)

## หลังอัปเดตแล้วเปิดไม่ขึ้น

1. รอให้หน้าเว็บแจ้งว่าการติดตั้งเสร็จจริง
2. ถอดสาย ปิดสวิตช์ รอ 5 วินาที แล้วเปิดใหม่
3. เสียบสาย USB และลองเปิดอีกครั้ง
4. หากยังไม่ขึ้น อย่าเลือกไฟล์หรือบอร์ดรุ่นอื่น ให้ติดต่อผู้ขายพร้อมแจ้งตัวเลือก Firmware ที่ใช้

## ข้อมูลที่ควรส่งเมื่อติดต่อ

- วันที่ได้รับสินค้า
- เลขคำสั่งซื้อหรือช่องทางที่ซื้อ
- อาการที่พบและชื่อเมนูที่กำลังใช้
- ภาพหรือคลิปที่เห็นตัวเครื่องและหน้าจอชัดเจน
- เวอร์ชัน Firmware จาก `SETTINGS → Device → Info` หากยังเปิดเมนูได้
- สิ่งที่ลองแก้ไปแล้ว

ดูช่องทางติดต่อที่ [การดูแล รับประกัน และติดต่อ](/help/care-warranty-support#ช่องทางช่วยเหลือ)

<Info>
🧩 **ต้องเพิ่มแผนภาพตรงนี้:** Decision Tree “เปิดไม่ติด → ปุ่มไม่ตอบสนอง → Storage → อัปเดต Firmware” สำหรับให้ลูกค้าเช็กตาม
</Info>
